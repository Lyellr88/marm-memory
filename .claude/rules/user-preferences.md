## UI/UX Design Philosophy

**Simpler UI is better UI - ruthlessly cut jargon and technical terms**  
**Use natural, conversational language instead of robotic/technical terms**  
**Progressive disclosure: show details in tooltips and modals when needed**  
**Consistency over novelty: uniform layouts, matching styles across the app**  
**Preservation is key: facelift not brain surgery - all features must behave as they did**  
**Iterative refinement: try multiple approaches until it feels right**  
**Center content in cards for visual balance**  
**Disabled states: cursor not-allowed, dashed border, darker background, 35% opacity**  
**Tooltips for depth: concise supporting text in UI, detailed explanations in data-tooltip**  
**Blue accent cards for emphasis: rgba(96, 165, 250, 0.08) background, 0.24 border**  
**Wrap-to-content cards: use fit-content width for variable-length items**  
**Focus features: blue outline with flash animation to guide user attention**
